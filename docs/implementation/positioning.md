# Project positioning

AegisSRE is an SRE and DevSecOps project with statistical detection,
evidence-backed reasoning and deployment intelligence. The
[acceptance ledger](status.md) separates implemented work from measured results.
Do not turn integration fixtures or planned targets into resume results.

## Supported resume wording

**AegisSRE | SRE, DevSecOps, Python, FastAPI, PostgreSQL, Redis, Kubernetes**

- Built a telemetry-driven reliability runtime with durable event processing,
  statistical/Isolation Forest detection, evidence-linked incidents, approvals
  and conservative recovery checks.
- Added authenticated APIs and console sessions, separate read/write credentials,
  scoped Kubernetes permissions, audit and disposable integration checks for
  persistence, transport and real scale/rollback actions.
- Implemented deployment risk snapshots, identified rollout windows, observed
  stable/canary comparisons and change-failure analytics, preserving unknowns.
- Built bounded fault injection and provenance-checked evaluation tooling that
  retains failed/censored outcomes and never treats timed cleanup as remediation.

Do not claim accuracy, MTTD/MTTR improvement, retrieval recall or eligible-action
success rates until the actual reviewed cohort establishes them. Base execution
remains simulation; an opt-in restricted backend has real integration proof.
That proof is narrower than production readiness or independent causal recovery.

## Portfolio introduction

AegisSRE collects telemetry, investigates incidents through read-only evidence
and keeps remediation behind policy, approval and recovery checks. Its deployment
intelligence combines empirical risk estimates, rollout evidence and observed
canary comparisons. Code, scoped integration proof and held-out acceptance are
reported separately. Local comparative evaluation is unfinished.

## Final release boundary

No live language-model inference or deeper MLOps build is required in this final
release. Training pipelines, a model registry, drift pipelines and future model
use may be mentioned as unbuilt roadmap ideas only. No v2 build is commissioned.
Statistical/Isolation Forest detection, evidence-only Ask, pgvector retrieval and
deployment risk/canary work remain in scope. No model download, remote inference
or spending is authorized by this document.
